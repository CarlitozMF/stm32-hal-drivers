◆ LCD_Init()

void LCD_Init ( const LCD_Config_t * config)

Ejecuta la secuencia de reseteo por software del HD44780, configura 2 líneas / matriz 5x8, incremento automático de dirección (Entry Mode), display encendido y cursor oculto. Debe llamarse una sola vez, antes de cualquier otra función del driver.

Parámetros
[in]configPuntero a la estructura de configuración de pines LCD_Config_t. Si es NULL, la función retorna sin hacer nada.

◆ LCD_PrintFloat()

void LCD_PrintFloat ( float value,
uint8_t decimal_places )

El redondeo se aplica sobre el valor completo, por lo que 0.999 con 2 decimales se muestra como "1.00". Casos especiales: NaN se muestra como "NaN" y valores con módulo mayor a 2.0e9 (incluye infinitos) como "Ovf".

Nota
La precisión útil de un float es de ~7 dígitos significativos.
Parámetros
[in]valueValor de tipo float a mostrar.
[in]decimal_placesCantidad de decimales (0 a LCD_FLOAT_MAX_DECIMALS). Con 0 no se imprime el punto decimal.
