void Utils_DelayUs_Init ( void )
Nota
Es idempotente: se puede llamar varias veces y no reinicia el contador DWT si ya estaba corriendo.

Inicializa el temporizador de retardos en microsegundos.

No reinicia CYCCNT si ya estaba en marcha, así no interfiere con otros usos del contador (profiling, timeouts).
